# Agent 指南模板

本文件包含两个独立区域。`core` 是可以自动安装和升级的通用规则；`project-template` 是交互式生成项目规则时使用的格式，不应把占位符原样复制到目标仓库。

**编写原则：** `AGENTS.md` 只写本仓库与模型/harness 默认行为的**差异**。不要重复「先规划再动手」「验证后再宣称完成」「根因调试」等已被工具与模型内化的通用习惯。
